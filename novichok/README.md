# Новичок — первые 90 дней

Локальный прототип рабочего места HR / руководителя для адаптации новых сотрудников: наставник, план из 8 шагов, просрочки, просьбы о помощи и журнал разговоров.

Демо-данные вымышлены. Прототип не связан с Битрикс24 и не отправляет данные на сервер: всё хранится в `localStorage` браузера.

## Быстрый запуск

Нужен Node.js 18+. Команды выполняются из папки `novichok` — там, где лежит этот README.

```bash
node server.js
```

Откройте http://localhost:5173. Порт можно изменить: `PORT=8080 node server.js`.

Можно и просто открыть `index.html` двойным щелчком — приложение статическое. Сервер нужен для одинакового поведения во всех браузерах и для запуска браузерных тестов.

## Проверка за 2–3 минуты

1. **Обзор.** Ожидаемые цифры: `11` сотрудников в первые 90 дней, `4` требуют внимания, `3` просроченных шага, `4` шага на сегодня. В таблице 12 строк, в сайдбаре у «Требуют внимания» стоит `4`.
2. **Мария Соколова.** Откройте карточку: два вопроса — не назначен наставник и просрочен шаг. Назначьте наставника (например, «Ольга Кедрова») и отметьте шаг «Познакомиться с кассой и правилами возврата». Счётчик внимания уменьшится `4 → 3`, план покажет `4 из 8 · 50%`.
3. **Илья Горин.** Запишите итог разговора с отметкой «Вопросы решены» и коротким текстом. Просьба о помощи закроется, счётчик внимания станет `3 → 2`.
4. **Перезагрузка.** Обновите страницу: изменения на месте, кнопка отмены неактивна — стек отмены живёт только до перезагрузки.
5. **Добавление.** Создайте сотрудника — появится карточка и план из 8 шагов, строк станет 13.
6. **Поиск и фильтры.** Запрос `кассир` оставляет одну строку (Софья Рощина). Подразделение «Склад» — 3 строки. Сортировка по имени ставит первой Анну Ладину.
7. **Вкладки.** «Просрочки» — 3 строки. «Шаги сегодня» — 3 сотрудника (у Софьи два шага, у Михаила и Евы по одному; всего 4 шага).
8. **Массовые действия.** Отметьте всех, удалите и нажмите «Отменить» в уведомлении — все 12 строк вернутся.
9. **Резервная копия.** Нажмите «JSON» — скачается файл с 12 сотрудниками. Импортируйте его обратно через меню действий: данные заменятся после подтверждения.
10. **Тема и мобилка.** Переключатель темы сохраняется после перезагрузки. На ширине 375px нет горизонтальной прокрутки, карточка сотрудника помещается в экран.

## Возможности

- Обзор с метриками и списком сотрудников; правила статусов вынесены в `js/core.js`.
- Карточка сотрудника: наставник, 8 шагов плана, журнал разговоров, история, расшифровка статусов.
- Добавление, редактирование и удаление сотрудников; удаление можно отменить.
- Массовое выделение и массовое удаление с отменой.
- Перетаскивание строк для ручного порядка.
- Поиск, фильтр по подразделению, сортировка, вкладки «Все / В первые 90 дней / Требуют внимания / Шаги сегодня / Просрочки».
- Сохранённые представления (до 20) с восстановлением фильтров.
- Экспорт и импорт JSON с проверкой схемы, дат, дублей и лимитов.
- Автосохранение в `localStorage`; при повреждённых данных приложение не падает, а показывает предупреждение и берёт демо-набор.
- Светлая и тёмная темы; мобильная раскладка от 375px.
- Доступность: skip-link, управление с клавиатуры, `aria`-атрибуты, фокус в диалогах, axe-core WCAG 2 A/AA без серьёзных нарушений.

## Правила статусов

Демо-дата зафиксирована: **11 ноября 2026**. От неё считаются все сроки.

- `future` — дата выхода ещё не наступила;
- `active` — с 1-го по 90-й день включительно;
- `finished` — после 90-го дня.

Сотрудник требует внимания, если он `active` и хотя бы одно условие верно:

- не указан наставник;
- есть просроченный шаг: срок прошёл, выполнение не отмечено;
- в последнем записанном разговоре отмечено «Нужна помощь».

Шаг считается просроченным, если он не выполнен и его срок меньше демо-даты. Шаг «на сегодня» — если срок равен демо-дате.

## Тесты

Из папки `novichok`:

```bash
npm install
npx playwright install chromium

npm test           # 24 юнит-теста, node --test
npm run test:browser  # 24 браузерных сценария, Playwright + axe-core
npm run test:all   # всё подряд
```

Юнит-тесты проверяют границы 1/90/91 дня, правила статусов, цифры демо-набора, валидацию битого JSON и неизменность доменных функций.

Браузерные сценарии проходят основной путь проверки, сохранение после перезагрузки, добавление/редактирование/удаление с отменой, поиск и фильтры, массовые действия, сохранённые представления, drag-n-drop, экспорт/импорт, XSS-экранирование, темы, мобильную ширину 375px и axe-core WCAG 2 A/AA на обзоре, инструкции и карточке сотрудника в обеих темах. Перед замером axe анимации отключаются, чтобы не ловить промежуточные кадры переходов.

## Ограничения прототипа

- Это не продакшен: нет бэкенда, авторизации, ролей и синхронизации между устройствами. Данные живут в одном браузере.
- Интеграции с Битрикс24 или другими HR-системами нет. Реальных HR-интервью, пилотов и замеров бизнес-эффекта не было.
- Не используйте реальные персональные данные: демо-режим и `localStorage` не обеспечивают защиту.
- Стек отмены хранится в памяти (до 30 действий) и очищается при перезагрузке.
- Проверено в Chromium через Playwright. Safari и Firefox не тестировались.
- Импорт проверяет схему, даты, дубли и лимиты, но не является границей безопасности.
- Современные CSS-возможности (`color-mix`, `:has`, `dvh`, `<dialog>`) требуют актуальных браузеров; в старых интерфейс может деградировать.
